## How to pick up the persisted install (after Phase 8 ships)

For developers / CI pulling this branch (or main, post-merge):

  1. Pull / checkout the branch with Phase 8 changes applied (.devcontainer/Dockerfile has a new `shellcheck \` line in the apt-get install block).
  2. Rebuild the devcontainer to pick up the Dockerfile change:
       - In VS Code:           Command Palette -> "Dev Containers: Rebuild Container" (or "Rebuild Without Cache" for a fully clean build)
       - In GitHub Codespaces: `gh codespace rebuild --full` (or use the Codespaces menu in the browser)
  3. Verify:
       which shellcheck                       # expect: /usr/bin/shellcheck
       shellcheck --version                   # expect: any apt-shipped version on bookworm

After rebuild, the ~/.local/bin/shellcheck hot-install (if still present) is shadowed by /usr/bin/shellcheck via PATH ordering. Both can coexist harmlessly; the system-installed copy takes precedence.
