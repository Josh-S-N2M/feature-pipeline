# Master Audit Checklist

Copy this into your working response when starting an audit. Check off items as you complete them. Helps keep the audit on track across turns.

```
Audit progress for <skill-name>:

- [ ] 0. Located SKILL.md at <path>
- [ ] 1. Ran audit_skill.py and read the JSON output
- [ ] 2. Read SKILL.md
- [ ] 3. Read each linked reference file
- [ ] 4. VERIFIED each script-derived MAJOR/BLOCKER against the file (form vs function)
- [ ] 5. Checked dim 1: Discoverability (read descriptions-and-triggering.md)
- [ ] 6. Checked dim 2: Frontmatter validity (read frontmatter-spec.md)
- [ ] 7. Checked dim 3: Token economy (read content-quality.md)
- [ ] 8. Checked dim 4: Progressive disclosure (read progressive-disclosure.md)
- [ ] 9. Checked dim 5: Instruction quality (covered by content-quality.md)
- [ ] 10. Checked dim 6: Workflow soundness (read workflows-and-feedback.md, or marked N/A)
- [ ] 11. Checked dim 7: Script hygiene (read scripts-and-code.md, or marked N/A)
- [ ] 12. Checked dim 8: Security posture (read security-checklist.md)
- [ ] 13. Checked dim 9: Anti-pattern absence (read anti-patterns.md)
- [ ] 14. Checked dim 10: Agent-fit (covered by content-quality.md)
- [ ] 15. Computed scores, applied verdict thresholds
- [ ] 16. Wrote audit-report-<skill-name>.md
- [ ] 17. Listed disclosed false-positive classes in report Notes (link, security, orphan, TOC, etc.)
- [ ] 18. If SECURITY-BLOCK: surfaced at top of report and recommended halt
```
